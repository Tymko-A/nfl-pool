Password setup

Each entrant sets their own password here, on their own machine. The password itself is never saved or sent anywhere — this page turns it into a one-way hash, and only the hash goes in pool.json.

Shown as plain text on purpose so you can check it before you commit to it.


    
Commit the change and the site will accept that password on the next deploy.

  


  

    
    
    
      
  1. Download this file and open it in a browser — it works offline, no server needed.
    2. 
      
  2. Each person picks their name, types a password, clicks Generate.
    3. 
      
  3. They send you the generated line (it contains no password, only a hash).
    4. 
      
  4. You paste all nine lines into pool.json and commit.
    5. 
    

    
Fair warning: this is friendly-pool security, not bank security. The hashes are
    public once the site is deployed, so a very weak password could be guessed by someone determined.
    210,000 PBKDF2 iterations makes that slow and tedious, which for nine friends is plenty.
